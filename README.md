# TaskMgr — диспетчер задач на Rust

Замена встроенному диспетчеру задач Windows: процессы деревом и по приложениям, графики
ЦП / памяти / диска / сети / GPU, службы, сетевые подключения, автозагрузка, трей.

**Стек:** `eframe`/`egui` (интерфейс), `sysinfo` (данные о системе), `winreg`, `tray-icon`, `windows-sys` (только Windows).

## Запуск

1. Установи Rust: https://rustup.rs (на Windows выбери MSVC-вариант).
2. В папке проекта:

```powershell
cargo run --release
```

Готовый exe: `target\release\TaskMgrRS.exe`.

## Как получить и поставить (без Rust и Visual Studio)

1. Выложи папку проекта в репозиторий на GitHub (в нём уже есть `.github/workflows/build.yml`).
2. Вкладка **Actions** → последний запуск «Build Windows exe» → внизу **Artifacts → TaskMgrRS**. Скачается zip с `TaskMgrRS.exe`.
3. Распакуй, запусти `TaskMgrRS.exe`. **Настройки → «Использовать эту программу вместо стандартного»** → подтверди окно UAC.

Готово: Ctrl+Shift+Esc открывает TaskMgr. Назад — та же кнопка в настройках («Вернуть стандартный диспетчер»).
Запасной вариант отката: `recover.bat` (двойной щелчок). Сборка вручную: `cargo build --release` (нужны Rust и C++ Build Tools).
Из командной строки: `TaskMgrRS.exe --install` / `--uninstall` (от администратора). Скрипты `install.ps1` / `uninstall.ps1` остались как альтернатива.

## Надёжность запуска

- `--selftest` — проверка без окна (счётчики, все вкладки, автозагрузка); код возврата 0 — всё в порядке.
- Если видеодрайвер не тянет wgpu, программа сама перезапускается на OpenGL (`--renderer=glow`; принудительно: `--renderer=wgpu|glow`).
- Любой сбой при старте показывается окном, подробности пишутся в `%APPDATA%\TaskMgrRS\crash.log`.
- Второй запуск не плодит окна, а показывает уже открытое.
- Неудачи фоновых запросов (службы, подключения, пользователи) показываются в интерфейсе и не роняют программу.

## Возможности

### Процессы
- Три режима: **список**, **дерево** (родитель → потомки, сворачивание веток) и **по приложениям**
  (как в диспетчере Windows 11: одинаковые программы сгруппированы, в заголовке сумма).
- Колонки: ЦП, память, диск, GPU, PID, состояние, время работы, пользователь, путь. Набор настраивается («Колонки ▾»),
  числовые ячейки подсвечиваются «тепловой картой», в заголовках итоги по системе.
- Поиск по имени, PID, пользователю, пути и командной строке; сортировка по клику на заголовок.
- Панель деталей: графики ЦП и памяти выбранного процесса, путь, командная строка, рабочая папка, родитель, приоритет.
- Действия (кнопки и правый клик): завершить, **завершить дерево**, **приостановить / возобновить**,
  **приоритет** (низкий … высокий, «режим эффективности»), открыть расположение файла, поиск в интернете,
  копирование PID / имени / пути / командной строки.
- Критичные процессы (`csrss.exe`, `lsass.exe`, `wininit.exe` и т. п.) и сам TaskMgr не завершаются.
- Экспорт списка в CSV (кнопка справа вверху) — файл появляется на рабочем столе, открывается в Excel.

### Производительность
ЦП (общая загрузка и график по каждому ядру), память и подкачка, диск (чтение / запись, тома с заполнением),
сеть (приём / передача, интерфейсы), GPU (загрузка и видеопамять, если система отдаёт данные).

### Службы
Список служб Windows, запуск / остановка / перезапуск, поиск, фильтр «только работающие».

### Подключения
TCP-соединения и UDP-порты с процессом-владельцем, фильтры по протоколу и состоянию, автообновление,
переход «Показать в процессах».

### Автозагрузка
Записи из реестра (`Run`) и папок «Автозагрузка», включение и выключение галочкой (как в диспетчере Windows).

### Прочее
- «＋ Новая задача» (Ctrl+N): запуск программы, папки или ссылки, в том числе от имени администратора.
- Трей: крестик сворачивает программу в трей (отключается в настройках).
- Настройки: скорость обновления (пауза, 0,5–5 с), поверх всех окон, подтверждение завершения деревьев.
  Хранятся в `%APPDATA%\TaskMgrRS\settings.json`.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+F | поиск по процессам |
| Ctrl+N | новая задача |
| Ctrl+1 … 6 | вкладки |
| F5 | обновить сейчас |
| Delete | завершить выбранный процесс |
| ↑ ↓ ← → | выбор строки, сворачивание и раскрытие веток |
| Esc | очистить поиск / снять выбор |

> Чтобы завершать системные процессы, управлять службами и видеть пути всех процессов, запускай программу от имени администратора.

## Структура

| Файл | Назначение |
|---|---|
| `src/install.rs` | замена и возврат системного диспетчера из программы (UAC) |
| `src/boot.rs` | журнал, окно ошибки, единственный экземпляр |
| `src/main.rs` | каркас приложения, боковая панель, строка состояния, горячие клавиши, диалог «Новая задача», настройки |
| `src/procs.rs` | вкладка процессов (список / дерево / группы, детали, действия) |
| `src/perf.rs` | вкладка производительности |
| `src/services.rs`, `src/conns.rs`, `src/startup_tab.rs` | службы, подключения, автозагрузка |
| `src/metrics.rs` | сбор ЦП / памяти / диска / сети / GPU и истории для графиков |
| `src/winproc.rs` | приостановка и приоритет процессов (Windows API) |
| `src/winquery.rs` | службы и подключения через PowerShell (JSON), фоновые задачи |
| `src/startup.rs`, `src/tray.rs` | автозагрузка (реестр) и иконка в трее — только Windows |
| `src/widgets.rs`, `src/theme.rs`, `src/settings.rs` | графики и виджеты, тема, настройки |

## Тесты

```powershell
cargo test
```

Покрыты разбор данных служб и подключений, форматирование, настройки, экспорт CSV, построение дерева и групп
(циклы родителей, свёрнутые ветки, переход к процессу), а также отрисовка всех вкладок и режимов без окна.
